# Week 38: 返せ

## 核動詞
「返す」（RETURN / REFLECT）

## リスク / リターン
- **リスク**: 扇に弾がある短い間だけ返せる。空振りするとその弾が扇を抜けるまで返せない。連打は窓を潰す。
- **リターン**: 扇のどこでも返せば通常の返し。黄色が薄い中心の弧で返すと弾がウルトに化け、太く速く敵を貫く。連続成功でコンボ。3コンボのウルトはさらに太い。

## 切ったもの
- チュートリアル部屋（開始ポップアップ3枚のみ：あなた／薄い弧／ウルト）
- 複数敵種（弾を撃つ1種の位置・速度・サイズ・HP差分のみ）
- 部屋移動・重力反転・位置入れ替え・設置爆発（W35–W37 の核は持ち越さない）
- 移動メイン操作（微左右のみ任意。主操作は返す1ボタン）

## 適用した桜井政博の教え / autonomous-game-development
- 「コアはリスク／リターン。フックは一つに全注ぎ。」（N 企画コンセプト）
- 「ヒットストップ 0.05〜0.1秒。手応えの核。」（D 仕様）
- 「起動即コア。プロローグや練習部屋を作らず、本番のLv1で学ばせる」（C 企画設計）
- **ゲーム性の定義**: リスク（窓外し＝被弾）とリターン（敵弾で敵を倒す）の直結（B）。
- **ギュッ→パッ**: 弾接近の緊張 → ヒットストップ＋シェイクで解消（B, G）。
- **即リトライ**: 死亡から1秒以内・暗転なしで同WAVE再開（B, D）。
- **デコボコ**: 開幕→尖り→息継ぎ→尖り→厚み（フェイク）→ピーク。平坦な坂にしない（C）。
- **救済**: 同WAVE2死で「次へ」スキップ（作者基準の難しさを捨てる）。
- **予兆と反応**: 敵の予兆フラッシュ＋照準線。見えない即死は作らない。
- **加算グロー禁止**: VFXは不透明芯＋黒縁のみ。
- **Mash to Start / Huge START**: タイトル連打で即howto→本番。
