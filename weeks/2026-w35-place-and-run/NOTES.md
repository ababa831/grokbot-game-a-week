# Week 35: Place and Run

## 核動詞
「置く」

## リスク / リターン
- **リスク**: 攻撃判定の発生地点を「未来の自分の通り道」に前もって設置するため、設置中の無防備な隙と、未来の自分自身がその攻撃ゾーンに突っ込む危険を背負う。
- **リターン**: 敵の移動経路を先読みして罠を重ねることで、大ダメージの一括解消と安全地帯の確保が得られる。

## 切ったもの
- 複雑な敵AI（直線追尾とパラメータ差分のみに単純化）
- 複数武器・スキルツリー（1種類の設置アクションに絞り込み）
- ストーリー導入とチュートリアル専用ステージ

## 適用した桜井政博の教え
- **ゲーム性の定義**: リスク（自爆危険と設置隙）とリターン（一網打尽）の直結（B1, B2）。
- **ヒットストップ**: 接触時に0.06秒（包み3+は0.1秒）停止させ、手応えを強調（D1）。
- **即リトライ**: 死亡演出をカットし、1キーで即座に再配置・リトライ（B3, D2）。
- **入力即スナップ**: 設置キー押下と同時に構えフレームへ即座に遷移（G1）。
- **Day 5 機能凍結**: 追加ステージ構想を切って単一アリーナのパラメータ調整に専念（E2, M2）。
