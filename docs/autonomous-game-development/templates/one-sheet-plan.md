# ペラ1枚企画書テンプレート（One-Sheet Plan Template）

AIがゲーム企画を立案・要約する際に使用する標準フォーマット。
A4用紙1枚（またはスクロールなしの1画面）に収めるため、余計な世界観ポエムや長大なアイテム一覧を排除し、以下の5項目のみを凝縮して記述する。

---

```markdown
# [ゲームタイトル（仮）]

## 1. ゲームの核（イミュータブル・コアバリュー）
> 「【対象プレイヤー】が、【核となる動詞】によって、【得られる快感・感情】を味わうゲーム」
※一文（20文字以内）で定義。以降の機能追加の採否基準となる不変定数。

## 2. 基本画面レイアウト（ASCIIアート / ブロック図）
+-------------------------------------------------------+
| [SCORE: 00000]   [LIFE: ♥♥♥♡♡]    [TIME: 059] [PAUSE]  |
|                                                       |
|                     [ 敵編隊 v v v ]                  |
|                                                       |
|                                                       |
|       [足場]                                 [足場]   |
|                                                       |
|                  [ プレイヤー (P) ]                   |
| ===================================================== |
| [地表 / HAZARD ZONE]                                  |
+-------------------------------------------------------+
- **視点・解像度**: 2Dサイドビュー（固定画面 / 横スクロール） / 1920x1080想定
- **主操作入力**: 移動（←→）、ジャンプ（Space / Aボタン）、攻撃（Z / Xボタン）

## 3. コアループ（3ステップ / 5〜15秒サイクル）
1. **課題提示（Risk）**: 画面上部から敵が接近。地上にとどまると包囲される。
2. **操作実行（Action）**: 短押しジャンプで足場へ跳び移り、空中ホールドで溜め攻撃を放つ。
3. **快感・報酬（Return）**: 敵編隊が一掃され、スコアアイテムが飛散。ヒットストップと画面揺れで爽快感。

## 4. 独自性（決定的な違い1点）
- **クロスドメイン組み合わせ**: 【既存要素A】 × 【既存要素B】
  - 例: 「落ち物パズル」×「打ち上げ花火」
- **引き算と多目的化**: 
  - 【ボタン/オブジェクト名】が、「攻撃」と「高速移動」の2つの役割を兼ねる。

## 5. ターゲット層とスキルキャップ制約
- **想定プレイヤー**: 【アクション初心者 / カジュアル層 / コアゲーマー】
- **同時入力数上限**: 最大【2】ボタン同時押しまで
- **1画面内同時認識敵数**: 最大【4】体まで
- **プロトタイプ検証仮説**: 「【検証したい操作や触感の問いを1点のみ記述】」
```
