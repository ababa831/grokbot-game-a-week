# AIセルフレビュー統合チェックリスト（Self-Review Checklists）

自律ゲーム開発における各フェーズの完了前セルフチェックリスト。
AI自身が出力前にこのチェックリストを精査し、すべての項目をクリアしていることを確認する。

---

## 1. 企画フェーズ・セルフチェック（Phase 1: Planning）
- [ ] **ペラ1枚制約**: A4用紙1枚（またはスクロールなしの1画面）で全容と主操作が一目で把握できるか？
- [ ] **画面レイアウトの可視化**: ASCIIアートまたはブロック図が含まれ、プレイヤーの視界・HUDが具体化されているか？
- [ ] **イミュータブル・コアバリュー**: ゲームの最も面白い瞬間を一文（20文字以内）で言い切れているか？
- [ ] **直結性**: 実装予定の全システムが、コアバリューを直接支えるために存在しているか？
- [ ] **引き算と多目的化**: 単一のボタンやシステムが複数の役割（攻撃と移動、攻撃と防御等）を兼ね備えているか？
- [ ] **既存の直感**: 広く知られたルールや日常の直感（重力、反射、相性等）が土台として機能しているか？
- [ ] **ターゲットとスキルキャップ**: ペルソナが固定され、同時入力数や認識負荷の上限が定義されているか？
- [ ] **検証仮説の単一化**: プロトタイプが「単一の問い」に答える最小コードになっているか？

---

## 2. 仕様フェーズ・セルフチェック（Phase 2: Specifications）
- [ ] **決定論的記述**: 「適度に」「いい感じに」「かっこよく」等の主観的・曖昧な表現がゼロか？
- [ ] **数値定義の完備**: 発生・持続・硬直フレーム、移動速度、加速度、判定サイズが単位付き数値として定義されているか？
- [ ] **状態遷移の網羅**: アクションの遷移図（State Machine）と入力優先度（Priority Matrix）が定義されているか？
- [ ] **境界条件（Edge Cases）の解決**:
  - 同時押し時の優先順位が決定されているか？
  - 画面外・崖端・障害物接触時の座標クランプ規則が定義されているか？
  - HPゼロと攻撃命中が同一フレームに発生した際の勝敗・処理優先度が定義されているか？
  - ポーズ中・画面遷移中の入力受付・破棄ルールが定義されているか？
- [ ] **画面遷移の完結性**: タイトル → メインループ → リザルト → 再開のフローが完全に閉じているか？

---

## 3. 手触り（Game Feel）セルフチェック（Phase 3 & 5: Game Feel）
- [ ] **ヒットストップ**: 命中時に攻撃側・被弾側のアニメーションのみが独立タイマーで3〜10F停止し、微小振動しているか？（物理・入力・ポーズUI・解除タイマーは継続更新）
- [ ] **非対称重力**: ジャンプ下降時の重力が上昇時の1.5〜2.0倍に設定され、キビキビ着地するか？
- [ ] **可変ジャンプ**: ジャンプボタンを途中で離した際、上昇速度がカットされ低ジャンプになるか？
- [ ] **コヨーテタイム**: 足場から落下した直後（5〜8F猶予）でもジャンプが発動するか？
- [ ] **先行入力バッファ**: 着地直前（5〜8F猶予）のジャンプ入力が保持され、着地と同時に発動するか？
- [ ] **重量感の緩急**: 重い技において、長めの予備動作（Windup）と一瞬の振抜き（Active）のコントラストがあるか？
- [ ] **カメラのデッドゾーン**: キャラクター中心にリジッド固定されず、適度な遊びと滑らかな減衰追従があるか？
- [ ] **カメラの先読み**: 水平移動時、進行方向の視界（Look-Ahead Offset）が広く確保されているか？
- [ ] **ゼロ待機UI**: メニュー・画面遷移が0.1〜0.15秒以内に完了し、連打によるスキップが可能か？
- [ ] **視認性の担保**: 暗い/明るい背景でもテキストやアイコンが縁取り・黒帯により100%読めるか？
- [ ] **プレイヤーフリーダム**: 会話の瞬間全文表示、カットシーンスキップ、完全ポーズが実装されているか？

---

## 4. ゲーム性・駆け引きセルフチェック（Phase 4 & 5: Gameplay）
- [ ] **リスクとリターンの連動**: 最大リターンを得る瞬間、被弾・失敗リスクが最大化しているか？
- [ ] **ノーリスク戦術の排除**: 遠距離連射や画面端待ちが「最も安全で効率的な最適解」になっていないか？
- [ ] **緊張と緩和のサイクル**: チャージ等の抑圧フェーズと、それを一気に晴らす解放フェーズがあるか？
- [ ] **敵の動的プレッシャー**: 敵が単なる的ではなく、プレイヤーの定位置待ちを崩す行動（移動や回避の強制）を持っているか？
- [ ] **支配的戦略の排除**: 3すくみ等の循環関係があり、すべての強力な行動に低コストの対抗手段があるか？
- [ ] **納得感のある予兆**: 致命傷を与える敵の大技に、人間が視覚・聴覚で反応できる予兆（Windup ≥ 15F）があるか？
- [ ] **理不尽な即死の排除**: 見えない落とし穴や画面外からの不意打ち即死がなく、多段階のセーフティがあるか？
- [ ] **リトライ摩擦の極小化**: ミスから再操作まで数秒以内で復帰し、難所の直前から再開できるか？
- [ ] **認知バイアス適応型乱数**: 純粋乱数による理不尽（90%が3連続失敗等）を防ぐ擬似乱数（PRD）が機能しているか？
- [ ] **マイクロ・コアループ**: 5〜15秒の基本ループが、装飾なしの幾何学図形だけでも操作していて面白いか？
