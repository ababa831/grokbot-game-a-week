# A — 仕事の姿勢

出典: 桜井「ゲーム作るには」プレイリスト。姿勢・ディレクター・行動原則。

## コンセプトと決断

- **プランB禁止。** 逃げ道を用意した瞬間、本線が薄くなる。
- **コンセプトは貫く。** 途中で曲げない。
- **多数決は凡庸。** 尖りは個から出る。
- **ディレクターは個。** 切る仕事も個の責任。

## 目的とエネルギー

- **目的はプレイヤーを楽しませること。** それ以外は手段。
- **内圧を実装に注ぐ。** 不満やこだわりは口ではなくコードと仕様へ。
- **企画は強火でザッと。** 煮込みすぎない。
- **とにかくやれ。** 作ったほうがエライ（企画設計とも接続）。

## 人間関係

- **ケンカするな。**
- **役割と人格を混同しない。** 役割上の要求と個人攻撃を分ける。

## アイデア

- **アイデアはテーマを決めて量産。** テーマなしの散発は弱い。

## 成果の見方

- **苦労は忘れる。作品は残る。**
- **1週間を体験の言い訳にしない。** 短い期間でも体験の質は落とさない。

## Game A Week への落とし込み

- **Day1にコアを一つ決めて曲げない。**
- **詰まったら量で突破し、初日に作り始める。**
