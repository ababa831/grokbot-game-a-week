# 仕事の姿勢

## 教え
- プランBに頼るな。最善を一つ出して責任を取る。調整は後。
- 価値観の幹と枝先。幹（広い層）か枝（ニッチ）かを意識して狙う。自分の好みだけにしない。
- インプットを太くアウトプットも太く。広く遊んで、出し続ける。
- 内圧をカンカンに高める。アイデアを先に溜めて逃ささない。企画書と実装に注ぐ。
- 無意味な多数決は無難で凡庸になる。監督が決める。
- 暗示の力。締切や恐怖も推進力になる。
- コンセプトは貫くもの。途中で曲げると資源と士気が死ぬ。
- 競争と豊穣。全ゲームと時間を争う。自己満足で終わらせない。
- 言ったことはそうなっていく。否定の言葉を行動の言葉に置き換える。
- エコーチェンバーを避ける。賛同だけで客観を失うな。
- 遊びの仕事は遊びじゃない。目的は常にプレイヤーを楽しませること。
- プレゼンはスピード。脂肪を削る。
- お客さんに説明できるか。制作都合を体験に出さない。
- 仕様変更は避けたいが致命傷ならすぐ言う。事実を集めて決断する。
- 企画書は絵が大きく、文章は数行。
- 企画は強火でザッと熱いうちに。哲学はプレイヤーに届かない。核がつまらなければ文書では救えない。
- 苦労は忘れる、作品は残る。楽するための手抜きは永遠に残る。
- ディレクターは個。独自の感性を入れる。
- とにかくやれ。0→1は手を動かす。やる気は後からついてくる。
- 長期出力は使命感で潰さない。軽い姿勢と続く手順を作る。
- アイデアが出ないときはテーマを決めて量を出す。荒唐無稽でも連鎖を止めず後で濾す。
- 絶対にケンカするな。業界は狭い。恨まず、残務を残さず去る。同僚は味方。
- 上は下なり下は上なり。役割≠人格。敬語とさん付け。リーダーはスタッフなしでは何もできない。

## Game A Week
- Day1にコアを一つ決めて独裁的に進める。A/B検討はしない
- 途中でコンセプトを変えない（3-4日目の「つまらない」に負けない。ただし致命傷のピボット時のみ見直し）
- アイデアを先に漏らさず、コードに落とす
- 締切を追い風にする。弱音を行動に置き換える
- 企画書に時間をかけず、熱いうちに手を動かして実装する
- 「1週間しかなかった」を体験の言い訳にしない
- 規模で勝負せず個のフックで勝つ
- 待ち時間ゼロ。テーマを置いて案を量産し、一本選んで初日に作り始める
- 詰まったら量で突破する
