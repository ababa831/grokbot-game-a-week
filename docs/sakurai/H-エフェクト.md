# H — エフェクト

出典: 桜井「ゲーム作るには」プレイリスト。合成・爆発・ヒット・パーティクル。

## 合成とレイヤ

- **加算だけはモヤる。** 不透明＋暗い色を使う。
- **キャラを埋めるな。** 2Dはキャラを上に。

## 爆発の順序

1. **閃光**
2. **パリッとした炎**
3. **残煙**
4. **即消える**

## シェイクとヒットマーク

- **シェイクは最大から減衰。**
- **ヒットマークは衝突点に 3–5f。** 高コントラスト。**ヒットストップ中も動かす。**

## パーティクル

- **短寿命。**
- **複数を1枚。** 枚数を増やしすぎない。
