# モーション

## 教え
- やりすぎがちょうどいい。
- 攻撃は待機・かまえ・打撃・硬直。
- かまえは即スナップ。入力即反応。
- 打撃は最高ポーズ。攻撃判定の瞬間を最高に見せる。
- 強さは硬直でバランス。フォロースルーの硬直で強さを抑える。
- スクワッシュ＆ストレッチ。縦潰し・横伸ばしを入れる。
- 被弾は即で極端シルエット。
- 補間はタメ長・実行1f。ブレンドは短く。
- 1軸回転禁止。判定と見た目を一致。

## Game A Week
- かまえは0フレーム。攻撃判定の瞬間を最高に見せ、硬直でバランスを取る
- ヒット時・着地時のスケール変形をコードで入れる
- やりすぎるくらい誇張する
- 判定と見た目を一致させる
