# G — モーション

出典: 桜井「ゲーム作るには」プレイリスト。攻撃・被弾・補間。

## 原則

- **やりすぎがちょうどいい。**
- **判定と見た目を一致。**

## 攻撃の4段

攻撃は次の並びで組む。

1. **待機**
2. **かまえ** — 即スナップ
3. **打撃** — 最高ポーズ
4. **硬直** — 強さは硬直でバランス

## 変形と被弾

- **スクワッシュ＆ストレッチ。**
- **被弾は即で極端シルエット。**

## 補間・ブレンド・回転

- **補間はタメ長・実行1f。** 溜めを長く、本番の一撃は1フレーム感。
- **ブレンドは短く。**
- **1軸回転禁止。** 単軸だけの貧しい回転にしない。
