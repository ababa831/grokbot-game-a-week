# K — プログラム

出典: 桜井「ゲーム作るには」プレイリスト。構成・パラメータ・習慣。

## ファイルと数値

- **ファイルは機能先英語。** 機能名を先に、英語で揃える。
- **数値は設定に出す。** コードに埋めっぱなしにしない。
- **口語パラメータ。** 調整する人が分かる名前にする。
- **物理はパラメータ化。**

## 進め方

- **高レベル命令で始めよ。** 細部のAPIから入らない。
- **チケットで可視化。**
- **動いたら即コミット。**

## デバッグ

- **デバッグを本体キーに。** 別ツールに閉じ込めない。開発中は本体から叩ける。
