# プログラム

## 教え
- ファイルは機能先英語。機能名を先に、英語で揃える。
- 数値は設定に出す。コードに埋めっぱなしにしない。
- 口語パラメータ。調整する人が分かる名前にする。
- チケットで可視化。
- 高レベル命令で始めよ。細部のAPIから入らない。
- 物理はパラメータ化。
- デバッグを本体キーに。別ツールに閉じ込めない。
- 動いたら即コミット。

- 数値・パラメータはすべて定数／設定ファイルに外出しする

- 動いたら即コミット
