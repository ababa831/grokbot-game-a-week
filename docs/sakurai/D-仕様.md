# D — 仕様

出典: 桜井「ゲーム作るには」プレイリスト。手触り・カメラ・カットの仕様値。

## 手触り

- **ヒットストップ 0.05–0.1秒。** 打撃の芯。
- **ジャンプは初速＋重力。** 複雑な軌道演算よりこの二軸。
- **即リスポーン。** 死んでからの待ちをなくす。
- **遅さは罪。** 反応・遷移・読み込み、すべて速いこと。

## カメラ

- **カメラは子にしない。** キャラの子オブジェクトにカメラをぶら下げない。

## 教えと運

- **教えるのは本番。** 本番外の教室を増やさない。
- **RNGは彩り、負けはスキル。** 運で負ける設計にしない。乱数は味付け。

## スコープと重心

- **Day5機能停止。** それ以降は機能を足さない。
- **重心をズラす。** 対称・平均に寄せすぎない。尖らせる。
