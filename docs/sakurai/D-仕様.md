# 仕様

## 教え
- ヒットストップ 0.05〜0.1秒。手応えの核。
- ジャンプは初速＋重力。複雑な軌道演算よりこの二軸。
- カメラは子にしない。キャラの子オブジェクトにカメラをぶら下げない。
- 遅さは罪。反応・遷移・待ち、すべて速いこと。
- 即リスポーン。死んでからの待ちをなくす。
- 教えるのは本番。本番外の教室を増やさない。
- RNGは彩り、負けはスキル。運で負ける設計にしない。
- Day5機能停止。それ以降は機能を足さない。
- 重心をズラす。対称・平均に寄せすぎない。

## Game A Week
- ヒットストップ必須（当たった瞬間に 0.05〜0.1秒 止める）
- 死亡・失敗から1秒以内に操作を返す。長時間の暗転・フェード・待ちは禁止
- Day5で機能凍結。残日は調整・バグ潰し・PR作成・提出準備
- 数値・パラメータはすべて定数／設定ファイルに外出しする
