# 雑談

## 教え
- 入力遅延を撲滅。遅さは罪。
- 賞や流行を追うな。過去すべてがライバル。
- マスターアップは切って出す。将来コストが利益を超えたら切れ。
- 64KB再利用。1体を色・顔・回転・ミラーで増やす。
- 住観せよ。現場・実物を自分の目で見る。
- ガイドラインを満たさないと出せない。出す条件を先に満たす。
- Game & Watchは静的状態の切替。
- 足跡のない雪で遊べ。痕跡が残らない場でも遊びを成立させる。
- なんでも対戦。ネット禁止。画面外は放置。
- 岩田: 論理で直す、怒らない。

## Game A Week
- 入力遅延を撲滅する。反応・遷移を速く保つ
- マスターアップは犠牲の上に立つ。残時間と価値を比較し、不要なこだわりを捨てる
- 1体の変形（色・顔・回転・ミラー／精霊方式）でバリエーションを出す
- 画面外を過剰管理しない
- 否定や弱音を行動（コード）に置き換える
