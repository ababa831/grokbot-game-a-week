# チーム

## 教え
- 後出しナシ。代案を添える。否定だけしない。
- 10人は7人分。人数がそのまま出力にならない。
- デバッグは終わらない。終わらせるのは決断。
- 即決。長引かせない。
- S／Aバグだけ直す。Cバグは残して出す。
- 平坦バランスより個。平均化しない。
- 小学生モニターは黙って観察。口を出さず見る。
- ディレクターは切る仕事。

## Game A Week
- 4〜5日分でスコープする
- Day5で機能追加を止め、黙って渡す（口頭説明なしで観察し、詰まる箇所を見る）
- S／A以外（Cバグ）は放置して線を引く
- 重い仕様・合わない要素は早い時点で切り捨てる
- 完成のために切る。残時間と価値を比較し、不要なこだわりを捨てる
