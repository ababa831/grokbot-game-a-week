# ゲーム性

## 教え
- ゲーム性＝リスクを冒してリターンを得るかけひき。どのデメリットを飲んでどのメリットを取るか。
- 上げすぎると一般性が死ぬ。思ったよりも下げる。
- 距離がリスク／リターンになる。強い行動には隙や近接リスクを乗せる。
- ギュッとしてパッと解消。ストレス→解消→報酬の短いサイクル。
- 平坦＝退屈。デコボコ。平均化は滅びの道。
- 穴は1つ残す。ズルい攻略の余地を全部塞がない。
- 浮遊感は落ちてこそ。落下・接地があるから浮く意味が出る。
- 敵は必須ではない。リスクの源は敵以外でもよい。
- リトライは迅速。失敗のコストを時間にしない。
- クリアできないより救済（スキップ／易化）。
- 報酬は良いことの量に比例する。
- 作者がギリギリクリアできる難度は、一般には無理。

## Game A Week
- すべてのコア動詞に明確なリスクとリターンを対応させる
- 欠点のない全方位攻撃は作らない。高リターンには隙を乗せる
- 単調な坂ではなく、意図的な谷と壁（デコボコ）を手置きする
- 即リトライ。死亡・失敗から1秒以内に操作を返す
- 作者基準の難度にせず、易化やスキップを最初から組み込む
- ピーキーな長所と短所を残し、平坦化しない
