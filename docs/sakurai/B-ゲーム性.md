# B — ゲーム性

出典: 桜井「ゲーム作るには」プレイリスト。ゲーム性の定義と調整。

## 定義

**ゲーム性 = リスクを冒してリターンを得るかけひき。**

これが全ての中核。かけひきが薄いとゲームではない。

## 難度と一般性

- **上げすぎると一般性が死ぬ。** 思ったよりも下げる。
- **作者がギリギリクリアできる難度は、一般には無理。**
- **クリアできないより救済**（スキップ／易化）。到達不能は体験を殺す。
- **平均化は滅びの道。** 尖りを潰さない。

## リスク／リターンの形

- **距離がリスク／リターン。** 近づく・遠ざかる・踏み込むが賭けになる。
- **ギュッとしてパッと解消。** 張力を溜めて一気に解放する。
- **平坦＝退屈。デコボコ。** 高低差・緩急が必要。
- **穴は1つ残す。** 全部塞がない。余白が遊びを生む。
- **浮遊感は落ちてこそ。** 落下・接地があるから浮く意味が出る。

## 敵・リトライ・報酬

- **敵は必須ではない。** リスクの源は敵以外でもよい。
- **リトライは迅速。** 失敗のコストを時間にしない。
- **報酬は良いことの量に比例。** 頑張った分だけ返す。
