# B — ゲーム性

## 教え
- **ゲーム性 = リスクを冒してリターンを得るかけひき。**
- 上げすぎると一般性が死ぬ。思ったよりも下げる。
- 距離がリスク／リターン。
- ギュッとしてパッと解消。
- 平坦＝退屈。デコボコ。
- 穴は1つ残す。
- 浮遊感は落ちてこそ。
- 敵は必須ではない。
- リトライは迅速。
- クリアできないより救済（スキップ／易化）。
- 報酬は良いことの量に比例。
- 平均化は滅びの道。
- 作者がギリギリクリアできる難度は一般に無理。

## Game A Week
- すべてのコア動詞に明確なリスクとリターンを対応させる。
- 即リトライ。作者基準の難度にしない。
- ピーキーな長所と短所を残し、平坦化しない。
