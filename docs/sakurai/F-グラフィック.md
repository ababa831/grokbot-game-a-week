# F — グラフィック

出典: 桜井「ゲーム作るには」プレイリスト。見え方・画風・確認環境。

## 描くもの・捨てるもの

- **光を描く。**
- **判定を強調。** 当たる場所が目で分かる。
- **見えない細部を捨てる。**
- **シルエットが全て。**
- **マンガ的デフォルメ。**
- **線を引いて出す。** 輪郭・ガイドで読みやすくする。

## 画風と色

- **画風統一。**
- **高彩度はプラモデル。** 塗りすぎ・色の張りすぎに注意。
- **奇数グリッド。** 偶数列の対称に寄りすぎない配置感覚。

## カメラ効果・仕上げ

- **DOFでミニチュア化するな。**
- **ブラー足しすぎるな。**
- **最終出力で統一。** バラバラの見た目を最後に揃える。

## 確認

- **安い画面で確認。** 良いモニタだけを信用しない。
