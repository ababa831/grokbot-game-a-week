# グラフィック

## 教え
- 光を描く。
- 判定を強調。当たる場所が目で分かる。
- 見えない細部を捨てる。
- 高彩度はプラモデル。塗りすぎ・色の張りすぎに注意。
- 画風統一。最終出力で揃える。
- 奇数グリッド。偶数列の対称に寄りすぎない。
- DOFでミニチュア化するな。ブラー足しすぎるな。
- 安い画面で確認。良いモニタだけを信用しない。
- シルエットが全て。マンガ的デフォルメ。線を引いて出す。

## Game A Week
- Day1で描画スタイル（パレット）を1つ確定する
- 背景は暗く落として前景・当たり判定を目立たせる。白黒でも読める明暗比
- 安いノートPCの画面で視認性を確認する
- 判定とシルエットを優先し、見えない細部は捨てる
