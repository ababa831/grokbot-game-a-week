# 広報

## 教え
- 開発×広報＝成果。黙って出さず、動いている核を端的に伝える。
- ゼロなら存在しない。出していないものは無いのと同じ。
- 製品像は正しく。実態と違う見せ方をしない。
- デモは1週間では作るな。短い周期ではデモ制作に逃げない。
- トレーラー必須。最初のフレームがゲーム画面。提示は速度。
- 市場調査禁止。調査に逃げず、出す。
- PRでフックを先に書く。
- 毎日スクショを残す。

## Game A Week
- GitHub PRの1行目はゲームの核となるフック・動詞を端的に書く
- Day7に3秒で伝わるGIF／スクショを用意して提出する
- 毎日スクショを残す
- 市場調査・A/B検討に時間を使わない
- 15秒のプレゼンを頭で行い、核が濁っていないか確認する
