# L — 広報

出典: 桜井「ゲーム作るには」プレイリスト。見せ方・トレーラー・日次記録。

## 開発と広報

- **開発×広報＝成果。**
- **ゼロなら存在しない。** 出していないものは無いのと同じ。
- **製品像は正しく。** 実態と違う見せ方をしない。

## デモとトレーラー

- **デモは1週間では作るな。**（Game A Week の短い周期ではデモ制作に逃げない）
- **トレーラー必須。**
- **最初のフレームがゲーム画面。**
- **提示は速度。** 見せるテンポを速く。

## 文言と調査

- **市場調査禁止。** 調査に逃げず、出す。
- **PRでフックを先に書く。**

## 記録

- **毎日スクショを残す。**
