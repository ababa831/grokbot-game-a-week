# UI

## 教え
- 読みやすさ優先。
- デフォルトフォント禁止。世界観に合う字体を当てる。
- スタート巨大。決定連打で即プレイ。
- 高コントラスト。背景を落として前景を目立たせる。
- ロゴ・会話は即スキップ。
- HUDは生存情報だけ。
- リマップを捨ててデフォルト操作を直感に。
- 言語なしでも絵で分かる。

## Game A Week
- エンジン／ブラウザ標準フォント禁止。初日にジャンル・世界観に合う無料フォントを当てる
- Mash to Start（タイトルで決定連打すれば即ゲーム開始）
- HUDは生存情報だけ。白黒でも読める明暗比を取る
- ロゴ・会話は即スキップ可能にする
