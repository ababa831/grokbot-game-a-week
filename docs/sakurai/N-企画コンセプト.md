# 企画コンセプト

## 教え
- コアはリスク／リターン。フックは一つに全注ぎ。
- 層で広げる。一本の芯の上に層を足す。
- 制約を機能に。制約がジャンルを決める。
- 短く易くもう一回。オムニバスで短く。プレイヤーを止めない。
- 2Pは主役と脇役。
- 合わない話は切る。途中の技術乗り換え禁止。
- ジャンルの疎外を解く。ジャンルのリスクを逆転。逆張り。
- 方向＋1ボタン。入力は最小でも深くできる。
- 1システムを極端パラメータで水増し。精霊方式（1敵を変形）。
- メカニクス先、テーマ後。
- Day1グレーボックス。

## Game A Week
- フックは1つ。90%の力を1つの独自メカニクスに注ぐ。余計なシステムを足さない
- Day1グレーボックス。テーマと核動詞を1つ決め、最小ループを組む
- メカニクス先、テーマ後。手応えがなければ絵で救おうとせず即ピボット
- 敵の種類を増やさず、1種類のサイズ・速度・パラメータを極端に振る
- 合わない話は切る。途中の技術乗り換え禁止
- 短く易くもう一回。プレイヤーを止めない
