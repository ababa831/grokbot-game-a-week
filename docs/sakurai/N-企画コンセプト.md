# N — 企画コンセプト

出典: 桜井「ゲーム作るには」プレイリスト。コアの広げ方・フック・制約。

## コア

- **コアはリスク／リターン。**
- **フックは一つに全注ぎ。**
- **メカニクス先、テーマ後。**
- **層で広げる。** 一本の芯の上に層を足す。
- **1システムを極端パラメータで水増し。**
- **精霊方式（1敵を変形）。** 種類を増やさず変形でバリエーション。

## 制約とジャンル

- **制約を機能に。**
- **制約がジャンルを決める。**
- **ジャンルのリスクを逆転。**
- **ジャンルの疎外を解く。** そのジャンルが人を遠ざける点をほどく。
- **逆張り。**

## 長さ・難度・人数

- **短く易くもう一回。**
- **オムニバスで短く。**
- **2Pは主役と脇役。**（一方が主役、他方が脇を支える構造）
- **プレイヤーを止めない。**

## 制作プロセス

- **Day1グレーボックス。**
- **合わない話は切る。**
- **途中の技術乗り換え禁止。**
- **方向＋1ボタン。** 入力は最小でも方向と一撃で深くできる。
