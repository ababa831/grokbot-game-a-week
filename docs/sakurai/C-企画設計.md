# C — 企画設計

## 教え
- 最初の3分が勝負。待たせず遊ばせる。
- チュートリアルは本番。
- 1ボタンでも深くできる。
- 分解してひねる。
- ほめてやれ。ノーリアクション禁止。
- プロローグ禁止。
- 作ったほうがエライ。
- 「○○みたい」で語らない。
- スコアはテーマ化。
- 大差ないのは面白くない。
- 色だけに頼らない。
- 入力読みAI禁止。
- 最初にクライマックス。
- いただく時間はコスト。

## Game A Week
- 起動即コア。プロローグや練習部屋を作らず、本番のLv1で学ばせる。
- Mash to Start。入力には必ず反応する。
- 「○○みたい」ではなくフックそのもので語る。
