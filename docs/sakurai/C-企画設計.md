# 企画設計

## 教え
- 最初の3分が勝負。待たせず遊ばせる。
- チュートリアルは本番。練習部屋を増やさない。
- 1ボタンでも深くできる。
- 分解してひねる。既存をバラしてねじる。
- ほめてやれ。ノーリアクション禁止。成功は直接称賛し派手に演出する。
- プロローグ禁止。最初にクライマックス。
- 作ったほうがエライ。語るより出す。
- 「○○みたい」で語らない。
- スコアはテーマ化。大差ないのは面白くない。
- 色だけに頼らない。識別や面白さを色に丸投げしない。
- 入力読みAI禁止。プレイヤー入力を先読みして誤魔化さない。
- いただく時間はコスト。プレイヤーの時間を奪う自覚を持つ。

## Game A Week
- 起動即コア。プロローグや練習部屋を作らず、本番のLv1で学ばせる
- Mash to Start。タイトルで決定連打すれば即プレイ
- 入力に対して無反応を作らない
- 「○○みたい」ではなくフックそのもので語る
- PR本文の先頭にフック・動詞を端的に書く
