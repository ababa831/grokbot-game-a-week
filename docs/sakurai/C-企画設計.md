# C — 企画設計

出典: 桜井「ゲーム作るには」プレイリスト。入り、教え方、スコア、語り方。

## 最初の体験

- **最初の3分が勝負。**
- **待たせず遊ばせる。**
- **プロローグ禁止。**
- **最初にクライマックス。** ピークを後ろに溜めない。
- **いただく時間はコスト。** プレイヤーの時間を奪う自覚を持つ。

## 教え方

- **チュートリアルは本番。** 別世界の練習場にしない。
- **ほめてやれ。ノーリアクション禁止。** 行動に必ず反応する。

## 深さの作り方

- **1ボタンでも深くできる。**
- **分解してひねる。** 既存をバラしてねじる。
- **作ったほうがエライ。** 語るより出す。

## 語り・表現の禁則

- **「○○みたい」で語らない。** 模倣ラベルで企画を説明しない。
- **色だけに頼らない。** 識別や面白さを色に丸投げしない。

## スコアと差

- **スコアはテーマ化。** 点数を世界観・目的に結びつける。
- **大差ないのは面白くない。** 差が体感できる設計。

## AI

- **入力読みAI禁止。** プレイヤー入力を先読みして誤魔化さない。
