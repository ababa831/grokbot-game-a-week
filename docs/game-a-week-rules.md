# Game A Week の法則

毎週従うオペレーティングルール。桜井まとめ39本の学びから、週次制作に直結するものを抜粋・再編した。

## ゲーム性の定義

**ゲーム性 = リスクを冒してリターンを得るかけひき。**

これが中核。距離がリスク／リターンになり、平坦は退屈、デコボコが面白い。上げすぎると一般性が死ぬので、思ったよりも下げる。穴は1つ残す。リトライは迅速。クリアできないより救済（スキップ／易化）。

詳細は [B-ゲーム性](./sakurai/B-ゲーム性.md) と [N-企画コンセプト](./sakurai/N-企画コンセプト.md)。

## Day1–Day7 のリズム

| 日 | やること |
|----|----------|
| **Day1** | コアを一つ決めて曲げない。グレーボックスで作り始める。詰まったら量で突破。プランB禁止。 |
| **Day2–Day4** | コアを深める。4–5日分のスコープに収める。フックは一つに全注ぎ。 |
| **Day5** | 機能停止。黙って渡す（カット）。Cバグは残して出す。 |
| **Day6** | 絵より音。SE・テンポ・無音の撲滅。 |
| **Day7** | 仕上げと即出し。マスターアップは切って出す。 |

### 姿勢（週を通して）

- コンセプトは貫く。1週間を体験の言い訳にしない。
- とにかくやれ。企画は強火でザッと。作ったほうがエライ。
- 目的はプレイヤーを楽しませること。内圧を実装に注ぐ。
- 苦労は忘れる。作品は残る。

## ハード制約

毎週の実装に対する固定ルール。

| 制約 | 内容 |
|------|------|
| **vanilla HTML/JS** | フレームワークを増やさない。単体で動くものに落とす。 |
| **one hook** | フックは一つ。そこに全注ぎ。 |
| **Day5 cut** | Day5で機能追加を止め、黙って渡す。 |
| **mash-to-start** | 決定連打で即プレイ。スタートは巨大。待たせない。 |
| **hitstop** | ヒットストップ 0.05–0.1秒。手触りの核。 |
| **instant retry** | 即リスポーン／迅速リトライ。死んでも止まらない。 |

### 補足（仕様から週次に落とすもの）

- 教えるのは本番（プロローグ禁止、チュートリアル＝本番）。
- 遅さは罪。入力遅延を撲滅。
- 最初の3分が勝負。最初にクライマックス。
- HUDは生存情報だけ。言語なしでも絵で分かる。
- 動いたら即コミット。毎日スクショを残す。
