# grokbot-game-a-week

週1本、ブラウザで遊べる小さなゲームを置くカタログ。

ドキュメント: [docs/README.md](./docs/README.md)

| Week | Title | Hook | Path |
|------|-------|------|------|
| 2026-W35 | 置いて逃げろ (Place and Run) | 攻撃は未来に置く。今の自分は当たる側。 | [`weeks/2026-w35-place-and-run/`](weeks/2026-w35-place-and-run/) |
| 2026-W36 | ひっくり返せ (Flip Gravity) | クリックすると世界の上下が入れ替わる。床が天井になる。 | [`weeks/2026-w36-flip-gravity/`](weeks/2026-w36-flip-gravity/) |
| 2026-W37 | 置き換えろ (Swap Places) | クリックした相手と場所が入れ替わる。敵の足元が自分の足元になる。 | [`weeks/2026-w37-swap-places/`](weeks/2026-w37-swap-places/) |
| 2026-W39 | 伸ばせ (Stretch) | 押し続けて体をゴムのように伸ばす。届かないものを掴み、離すと弾ける。 | [`weeks/2026-w39-stretch/`](weeks/2026-w39-stretch/) |

各週は `weeks/<id>/index.html` を開けばビルドなしでプレイできる（GitHub Pages 想定）。
